⚙️ Konfigurasi Variabel Lab

Isi variabel dari panel kiri Qwiklabs Anda. Seluruh perintah di bawah akan otomatis terpasang dengan nilai ini secara presisi.

Project ID dari panel kiri informasi Qwiklabs.
Region dari panel kredensial Qwiklabs sebelah kiri (di bawah GCP Project ID, misal: us-east1).
Zone dari panel kredensial Qwiklabs sebelah kiri (di bawah Region, misal: us-east1-b).
💡 Cara Menemukan Region & Zone:

Setelah menekan tombol Start Lab di Qwiklabs, buka petunjuk pengerjaan Task 1 (Build infrastructure) Langkah ke-3. Cari kotak kode provider "google" yang tampilannya seperti di bawah ini, lalu salin nilainya ke form di atas: 

provider "google" {
  project = "..."
  region  = "us-east1"   <--- Salin ini ke kolom REGION
  zone    = "us-east1-b" <--- Salin ini ke kolom ZONE
}
⚠️ Perhatian: Masih ada variabel yang belum diisi! Harap lengkapi semua form di atas agar skrip di bawah tidak berisi parameter kosong.

💡 Tips Tampilan Cloud Shell (Dari Catatan Video)
  • Jika font atau terminal Cloud Shell terasa terlalu besar dan terpotong, tekan Ctrl + Minus (-) pada browser Anda untuk melakukan zoom out.
  • Otorisasi Cloud Shell saat jendela pop-up meminta persetujuan kredensial API.

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Cloud Shell Terminal
⏳ Proses Memakan Waktu: Tunggu sekitar 1-2 menit hingga proses instalasi selesai dan perintah terraform --version menampilkan versi v1.5.7 atau yang lebih baru.
🚨 Terlanjur Error / Ingin Reset State Terraform dari Awal? Klik di sini
Jika Anda terlanjur menjalankan Langkah 2.2 / 3 tanpa mengecek progress Task 2 (sehingga muncul error "Please modify main.tf file and add 'tags'..." atau skor terhenti 10/20), jalankan perintah pembersihan total ini di Cloud Shell untuk mereset seluruh resource dan state Terraform secara bersih:
Bash - Emergency Reset Terraform State 
terraform destroy -auto-approve || true
rm -rf .terraform* main.tf* static_ip

Setelah perintah di atas selesai, Anda dapat memulai kembali pengerjaan dari Task 1 secara bersih dan lancar!

Task 1. Build Infrastructure

Buat berkas konfigurasi main.tf awal untuk mendefinisikan provider Google dan resource VPC Network .

💡 Kenapa Menggunakan Perintah cat <<EOF alih-alih Code Editor?

Mengedit berkas Terraform secara manual melalui Code Editor rentan terhadap kesalahan spasial/indentasi. Dengan mengeksekusi blok cat <<EOF > main.tf, berkas terbuat 100% presisi langsung dari terminal tanpa perlu berpindah tab.

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

⚠️ Penting: Sebelum menekan tombol Copy di bawah, pastikan parameter GCP Project ID, Region, dan Zone di dalam kode di bawah sudah tidak berupa placeholder (seperti <PROJECT_ID>, <REGION>, <ZONE>). Jika masih berupa placeholder, harap isi form variabel di bagian paling atas halaman terlebih dahulu!
Cloud Shell Terminal
⏳ Proses Memakan Waktu: Menjalankan terraform apply untuk membuat VPC Network memerlukan waktu sekitar 1 menit hingga status "Apply complete!" muncul.

🛑 STOP! JANGAN JALANKAN LANGKAH 2.2 SEBELUM CHECK PROGRESS!
Mengapa ini sangat penting?
Langkah 2.1 di atas baru saja membuat VM Instance dengan OS debian-12 dan tag ["web", "dev"] yang wajib diverifikasi oleh Qwiklabs terlebih dahulu.

Jika Anda langsung mengeksekusi Langkah 2.2 di bawah sebelum menekan tombol verifikasi, Langkah 2.2 akan mengedit OS disk dan mengeksekusi terraform destroy yang menghapus instance tersebut. Jika ini terjadi sebelum Anda mengecek progress, Qwiklabs akan mengeluarkan error: Please modify main.tf file and add 'tags' argument in vm instance using terraform.

Pastikan Task 2 sudah centang hijau di Qwiklabs sebelum lanjut ke Langkah 2.2!
