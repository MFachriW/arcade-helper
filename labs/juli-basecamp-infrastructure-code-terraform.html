⚙️ Persiapan: Akun & Instalasi Terraform

Atur kredensial sesi aktif dan pasang repositori resmi HashiCorp Terraform pada Cloud Shell Anda.

💡 Tips Tampilan Cloud Shell (Dari Catatan Video)
  • Jika font atau terminal Cloud Shell terasa terlalu besar dan terpotong, tekan Ctrl + Minus (-) pada browser Anda untuk melakukan zoom out.
  • Otorisasi Cloud Shell saat jendela pop-up meminta persetujuan kredensial API.

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Cloud Shell Terminal
⏳ Proses Memakan Waktu: Tunggu sekitar 1-2 menit hingga proses instalasi selesai dan perintah terraform --version menampilkan versi v1.5.7 atau yang lebih baru.

Task 1. Build Infrastructure

Buat berkas konfigurasi main.tf awal untuk mendefinisikan provider Google dan resource VPC Network .

💡 Kenapa Menggunakan Perintah cat <<EOF alih-alih Code Editor?

Mengedit berkas Terraform secara manual melalui Code Editor rentan terhadap kesalahan spasial/indentasi. Dengan mengeksekusi blok cat <<EOF > main.tf, berkas terbuat 100% presisi langsung dari terminal tanpa perlu berpindah tab.

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Cloud Shell Terminal
⏳ Proses Memakan Waktu: Menjalankan terraform apply untuk membuat VPC Network memerlukan waktu sekitar 1 menit hingga status "Apply complete!" muncul.

Task 2. Change the Infrastructure

Praktikkan penambahan resource VM Compute Instance, perubahan tags secara in-place, penggantian image disk (destructive change), dan penghancuran total infrastruktur.

Langkah 2.1: Tambah VM Instance & Perbarui Tags

Langkah 2.2: Destructive Changes (Ubah Disk) & Destroy

Mengubah OS disk memerlukan re-creation (replace resource). Setelah itu, lakukan pembersihan total menggunakan terraform destroy.

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Cloud Shell Terminal
⏳ Proses Memakan Waktu: Proses destroy membutuhkan waktu sekitar 1-2 menit karena Terraform memastikan instance dihapus sebelum VPC Network dapat di-teardown.
