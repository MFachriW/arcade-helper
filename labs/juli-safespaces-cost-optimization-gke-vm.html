Task 2. Choosing the right machine type for the Hello app

Skalakan workload Hello App dan amati bagaimana GKE membutuhkan node baru. Kemudian, migrasikan workload ke node pool baru yang lebih optimal secara biaya (binpacking).

Konsep: Binpacking & Optimalisasi Node

Binpacking adalah teknik menempatkan container secara efisien ke dalam node (VM) seminimal mungkin. Daripada menggunakan banyak mesin kecil (seperti e2-medium) yang menyisakan ruang kosong memori tidak terpakai, seringkali lebih hemat biaya menggunakan satu mesin yang lebih besar (seperti e2-standard-2) yang dapat menampung seluruh workload secara padat.

Langkah 3.3: Konfigurasi VPC Flow Logs & BigQuery (Manual UI)

Langkah Manual Google Cloud Console

  1. Biarkan terminal Cloud Shell di atas tetap melakukan ping. Buka tab browser baru ke Google Cloud Console atau minimalkan Cloud Shell.
  2. Navigasi ke menu VPC Network > VPC Flow Logs, lalu klik Enable the Network Management API (jika diminta).
  3. Klik tombol Add VPC flow logs configuration -> lalu pilih Add a configuration for subnets.
  4. Pada dropdown VPC networks, centang default, lalu klik OK.
  5. Cari baris subnet dengan region (gunakan kolom filter), klik Manage flow logs di bagian atas tabel -> lalu klik Add new configuration.
  6. Klik Add a configuration (di bawah Compute Engine API), lalu klik Done, dan terakhir klik Save.
  7. Navigasi ke menu Monitoring > Logs Explorer. Di panel atas, klik All log names, pilih vpc_flows, lalu klik Apply.
    ⏳ Catatan Penting: Jika nama log vpc_flows belum muncul segera di opsi All log names, harap tunggu sekitar 1 hingga 3 menit lalu refresh halaman console. Nama log ini akan muncul sendiri secara otomatis setelah traffic VPC Flow Logs mulai terakumulasi.
  8. Klik tombol Actions > Create Sink (di atas daftar log).
  9. Beri nama sink: FlowLogsSample, klik Next.
  10. Pada Sink destination, pilih BigQuery dataset. Lalu pilih Create new BigQuery dataset. Masukkan Dataset ID: us_flow_logs, klik Create dataset, lalu klik Create sink.
  11. Navigasi ke menu BigQuery. Buka dataset us_flow_logs -> klik tabel compute_googleapis_com_vpc_flows_xxx.
  12. Klik titik tiga di samping tabel compute_googleapis_com_vpc_flows_xxx, lalu pilih Query. Paste kode berikut tepat di antara kata SELECT dan FROM:
    jsonPayload.src_instance.zone AS src_zone, jsonPayload.src_instance.vm_name AS src_vm, jsonPayload.dest_instance.zone AS dest_zone, jsonPayload.dest_instance.vm_name
  13. Klik Run. Anda akan melihat log komunikasi lintas zona.
