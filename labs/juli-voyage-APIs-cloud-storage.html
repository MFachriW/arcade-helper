Task 1. Create two Cloud Storage buckets
Task 1

Membuat berkas JSON spesifikasi bucket dan memanggil Cloud Storage JSON API via HTTP POST untuk membuat Bucket 1 dan Bucket 2. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Bash - Create Buckets
Penjelasan Langkah & Konsep (Task 1)
  • POST HTTP ke Cloud Storage API: Endpoint POST /b?project=<PROJECT_ID> mendaftarkan bucket baru pada infrastruktur cloud Google.
  • OAuth Authentication Token: Perintah gcloud auth print-access-token menghasilkan string akses dinamis yang dikirimkan melalui header HTTP Authorization: Bearer ....
Task 2. Upload an image file to a Cloud Storage bucket
Task 2

Mengunduh berkas gambar sampel world.jpeg ke Cloud Shell, kemudian mengunggahnya ke Bucket 1 menggunakan Cloud Storage Media Upload API. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Bash - Upload Image
Penjelasan Langkah & Konsep (Task 2)
  • Upload HTTP Type - Media: Pengunggahan berkas biner/gambar dilakukan melalui endpoint upload khusus /upload/storage/v1/b/<PROJECT_ID>-bucket-1/o?uploadType=media&name=world.jpeg dengan mencantumkan header Content-Type: image/jpeg.
Task 3. Copy a file to another bucket
Task 3

Menyalin berkas gambar dari Bucket 1 ke Bucket 2 menggunakan API method copyTo langsung di sisi server cloud Google. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Bash - Copy File
Penjelasan Langkah & Konsep (Task 3)
  • copyTo API Method: Melakukan penyalinan data internal server-side dari satu bucket ke bucket lain tanpa memakan bandwidth atau mendownload berkas secara lokal.
Task 4. Make an object (file) publicly accessible
Task 4

Mengunggah file konfigurasi Access Control List (ACL) JSON untuk memberikan hak akses baca (READER) bagi semua orang di internet (allUsers) ke berkas gambar di Bucket 1. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Bash - Public Access
Penjelasan Langkah & Konsep (Task 4)
  • Access Control List (ACL) API: Mengontrol siapa saja yang berhak berinteraksi dengan berkas secara granular. allUsers mewakili publik umum tanpa login.
Task 5. Delete the object file and Bucket 1
Task 5

Menghapus berkas gambar world.jpeg di Bucket 1, kemudian dilanjutkan dengan menghapus Bucket 1 menggunakan API method DELETE. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Bash - Delete Bucket
Penjelasan Langkah & Konsep (Task 5)
  • DELETE HTTP API: Melakukan pembersihan resource. Sesuai aturan Cloud Storage, sebuah bucket tidak dapat dihapus jika di dalamnya masih terdapat berkas/objek data.
