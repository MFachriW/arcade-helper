☁️ Task 1. Enable sensitive data protection for Cloud Storage

Membuat Discovery scan harian untuk Cloud Storage bucket, membuat De-identify template untuk nomor kartu kredit, dan menjalankan De-identify job.

🛠️ Langkah 1: Buat & Jadwalkan Discovery Scan Configuration di Console

  1. Buka Google Cloud Console, lalu navigasi ke Navigation menu (☰) > Security > Sensitive Data Protection.
  2. Buka tab Discovery. Pada bagian Cloud Storage, klik Enable.
  3. Untuk Select scope, biarkan opsi Scan selected project, lalu klik Continue.
  4. Pada Managed schedules, klik Edit Default schedule, sesuaikan:
    • On a schedule: Reprofile Daily
    • When inspect template changes: Reprofile Daily
    • Klik Done, lalu klik Continue.
  5. Untuk Select inspection template, biarkan opsi Create a new inspection template tercentang, lalu klik Continue.
  6. Pada bagian Add actions:
    • Aktifkan Save data profile copies to BigQuery.
    • Dataset ID: cs_discovery
    • Table ID: cs_data_profiles
  7. Klik Continue pada bagian pemrosesan fallback.
  8. Untuk Set location to store configuration, pilih Multi_region > us (multiple regions in United States), lalu klik Continue.
  9. Isikan Display name: Cloud Storage Daily Discovery
  10. Klik Create, lalu konfirmasi dengan mengklik Create configuration.

🛠️ Langkah 2: Berikan Conditional Access pada Username 2 & Tag Dataset

  1. Buka Navigation menu (☰) > IAM & Admin > IAM.
  2. Cari baris untuk Username 2: <EMAIL_USER_2>, lalu klik ikon pensil (Edit principal).
  3. Ganti peran Viewer menjadi Browser (Klik ikon tempat sampah pada Viewer, lalu tambahkan role Basic > Browser).
  4. Pertahankan peran BigQuery Data Viewer, lalu klik tombol Add IAM condition.
  5. Isikan konfigurasi Condition:
    • Title: No SPII Access Only
    • Condition builder: Pilih Tag untuk Condition type 1, dan pilih has value untuk Operator.
    • Value path: <PROJECT_ID>/SPII/No
  6. Klik Save, lalu klik Save lagi pada panel IAM utama.
  7. Buka Navigation menu (☰) > BigQuery.
  8. Di panel Explorer sebelah kiri, luaskan ID Project: <PROJECT_ID>.
  9. Klik dataset bernama orders.
  10. Di panel sebelah kanan, klik Edit details (ikon pensil).
  11. Pada bagian Tags, klik Select scope > Select current project, lalu pilih:
    • Tag key: SPII
    • Tag value: No
  12. Klik Save.
🔍 Penjelasan Langkah & Konsep (Task 2)
  • Attribute-Based Access Control (ABAC): Pendekatan keamanan granular yang membatasi hak akses Username 2 hanya pada dataset BigQuery yang bertag SPII/No, sementara dataset sensitif seperti car_owners tersembunyi secara otomatis.
