Parameter Dinamis Lab

Penting: Kamu belum mengisi Nama Aplikasi dan/atau Email Akun Student. Harap lengkapi form di atas terlebih dahulu agar teks panduan tersusun rapi!
COMMON PROBLEMS (PENYEBAB UTAMA PROGRESS GAGAL 100%):
  1. Terjemahan Bahasa Otomatis (Website vs Situs): Jika browser/Google Sheets kamu memakai Bahasa Indonesia, nama kolom Website bisa otomatis terjemahkan menjadi Situs. Hal ini membuat Qwiklabs GAGAL mendeteksi progress. Pastikan kolom di Sheets dan AppSheet tetap bernama Website (Bahasa Inggris).
  2. Nama Google Sheets Saat Copy: Saat menyalin spreadsheet ke Drive kamu, pastikan nama filenya diubah menjadi companies. Jika masih bernama Copy of companies, sistem pengecekan progress tidak akan bisa membaca perubahannya!
  3. Input Form (Gunakan Copy-Paste & Hindari Autocomplete Alamat): Selalu copy-paste teks data yang diberikan agar tidak ada typo atau spasi berlebih. Saat mengetik Business Address, jika muncul rekomendasi dropdown yang menambahkan kata "Amerika Serikat" / "United States" di belakangnya, JANGAN DIKLIK. Cukup paste alamat asli lalu simpan!

Task 1: Create a new AppSheet app
Task 1
💻 Task ini diselesaikan secara langsung di AppSheet Console.
Panduan Langkah Manual:
  1. Buka platform AppSheet Console dan pastikan login menggunakan email: <EMAIL_STUDENT>.
  2. Klik tombol Create > pilih App > pilih Start with existing data.
  3. Pada isian App name, ketik persis: <NAMA_APLIKASI>.
  4. Pilih opsi sumber data Google Sheets, lalu cari dan pilih file spreadsheet bernama companies.
    ⚠️ Pastikan nama filenya 'companies', BUKAN 'Copy of companies'!
  5. Tunggu hingga AppSheet selesai memuat dan membuat draf aplikasi baru kamu.
Penjelasan Langkah & Konsep (Task 1)
  • Start with existing data: Memungkinkan AppSheet menganalisis header kolom pada Google Sheets secara otomatis untuk membentuk skema data dan tampilan dasar (*default views*).
  • Konsistensi Nama Aplikasi: Penamaan aplikasi harus sesuai dengan instruksi soal Qwiklabs (Company Details) agar sistem verifikasi dapat mendeteksi resource aplikasi kamu.
Task 2: Add a new company
Task 2
💻 Gunakan panel Emulator Preview di sebelah kanan editor AppSheet <NAMA_APLIKASI>.
Panduan Langkah Manual:
  1. Pada panel preview aplikasi di sebelah kanan editor, klik ikon tambah (➕) untuk membuka formulir penambahan data.
  2. Isi atribut formulir menggunakan metode Copy-Paste dengan nilai berikut:
    • ID: 11
    • Company Name: Cymbal Austin
    • Business Address: 500 W 2nd St, Austin, TX 78701
    ⚠️ Jangan klik opsi autocomplete yang menambahkan "Amerika Serikat" di belakang alamat!
  3. Biarkan kolom atribut lainnya kosong (blank).
  4. Klik tombol Save pada formulir preview.
Bash - Data Task 2 Summary
Penjelasan Langkah & Konsep (Task 2)
  • Preview Emulator: Melakukan pengujian langsung terhadap formulir input data sebelum aplikasi dipublikasikan ke pengguna umum.
  • Atribut ID Unik: Setiap baris data dalam AppSheet membutuhkan pengenal unik (Key) agar record baru tidak tertimpa.
Task 3: Update and regenerate your app's data structure
Task 3
Menambahkan kolom baru di Google Sheets dan memperbarui struktur kolom di editor AppSheet.
Panduan Langkah Manual:
  1. Buka file Google Sheets companies di Google Drive kamu.
  2. Tambahkan header kolom baru bernama Website pada Kolom G (kolom ke-7).
    ⚠️ Pastikan nama kolom ber-ejaan Bahasa Inggris 'Website', BUKAN 'Situs'!
  3. Kembali ke Editor AppSheet untuk aplikasi <NAMA_APLIKASI>.
  4. Buka tab menu Data di bilah navigasi kiri > pilih tabel companies.
  5. Klik tombol Regenerate Structure (atau ikon reload skema di bagian atas tabel).
  6. Cari kolom Website yang baru muncul di daftar kolom, lalu ubah Type-nya menjadi Url.
  7. Klik tombol Save di pojok kanan atas editor.
Bash - Data Task 3 Summary
Penjelasan Langkah & Konsep (Task 3)
  • Regenerate Structure: Memaksa AppSheet membaca ulang header kolom dari tabel Google Sheets jika ada penambahan atau perubahan skema data.
  • Tipe Data Url: Mengubah tipe data menjadi `Url` secara otomatis mengaktifkan tautan interaktif yang dapat diklik langsung oleh pengguna aplikasi.
Task 4: Deploy and test your app
Task 4
Memublikasikan aplikasi dan menguji penginputan data pada browser aplikasi yang telah di-deploy.
Panduan Langkah Manual:
  1. Pada Editor AppSheet aplikasi <NAMA_APLIKASI>, buka menu Manage > Deploy State (atau klik ikon peringatan status di pojok kiri atas).
  2. Klik tombol Run deployment check.
  3. Setelah pemeriksaan selesai tanpa error kritikal, klik tombol Move app to deployed state.
  4. Buka aplikasi yang sudah di-deploy melalui link browser atau mode preview penuh.
  5. Klik ikon ➕ untuk menambahkan data perusahaan baru dengan rincian (gunakan Copy-Paste):
    • ID: 12
    • Company Name: Cymbal Houston
    • Business Address: 3663 Washington Ave, Houston, TX 77007
    • Website: cymbal-houston.com
    ⚠️ Jangan klik saran autocomplete alamat yang menambahkan "Amerika Serikat"!
  6. Biarkan kolom lainnya kosong, lalu klik Save.
Bash - Data Task 4 Summary
Penjelasan Langkah & Konsep (Task 4)
  • Deployed State: Mengubah status dari *In Development* menjadi *Deployed* untuk memverifikasi bahwa aplikasi memenuhi standar publikasi AppSheet.
  • Testing Deployed App: Pengujian akhir pada lingkungan produksi langsung untuk memastikan seluruh fitur input data dan tipe data baru (`Url`) berjalan dengan sempurna.
