Persiapan: Instalasi Terraform

Terraform belum terpasang secara default di Cloud Shell. Jalankan perintah di bawah ini untuk mengunduh dan mengonfigurasi repositori HashiCorp agar instalasi bertahan selama sesi Cloud Shell.

Bash (Cloud Shell) 
cat <<'EOF' > ~/.customize_environment
wget -O - https://apt.releases.hashicorp.com/gpg | sudo gpg --yes --dearmor -o /usr/share/keyrings/hashicorp-archive-keyring.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/hashicorp-archive-keyring.gpg] https://apt.releases.hashicorp.com $(grep -oP '(?<=UBUNTU_CODENAME=).*' /etc/os-release || lsb_release -cs) main" | sudo tee /etc/apt/sources.list.d/hashicorp.list
sudo apt update && sudo apt install -y terraform
EOF
bash ~/.customize_environment

Untuk memverifikasi bahwa Terraform telah terpasang dengan benar, Anda dapat menjalankan perintah terraform --version.
