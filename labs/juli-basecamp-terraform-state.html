Work with Backends

Check My Progress

Pada tugas ini, Anda akan menginstal Terraform, mengonfigurasi backend lokal, membuat bucket Cloud Storage untuk menyimpan state file secara terpusat (GCS backend), serta memigrasikan state tersebut.

Eksekusi perintah-perintah berikut langsung di Cloud Shell secara berurutan.

Langkah 1: Instalasi Terraform & Aktivasi API

Atur repositori HashiCorp untuk menginstal Terraform secara permanen di Cloud Shell, serta aktifkan API Gemini Code Assist.

Bash

Langkah 2: Buat Konfigurasi `main.tf` dengan Local Backend

Buat berkas main.tf dengan backend lokal dan resource Cloud Storage bucket menggunakan Project ID Anda.

Bash
Penjelasan: Perintah di atas secara otomatis membuat file main.tf yang mendefinisikan Cloud Storage bucket bernama qwiklabs-gcp-XX-XXXXXXX serta backend penyimpanan status lokal pada direktori terraform/state/terraform.tfstate.

Langkah 3: Inisialisasi & Apply State Lokal

Jalankan inisialisasi backend lokal dan terapkan pembuatan resource bucket.

Bash

Langkah 4: Migrasi State ke Cloud Storage (GCS) Backend

Ubah konfigurasi backend di main.tf dari local menjadi gcs, lalu migrasikan berkas state ke Cloud Storage.

Bash

Langkah 5: Refresh State & Pembersihan (Cleanup)

Jalankan refresh state, kemudian kembalikan backend ke lokal dengan opsi force_destroy = true agar bucket dapat dihapus beserta konten di dalamnya.

Bash
Setelah menyelesaikan langkah-langkah di atas, klik tombol Check my progress pada Task 1 di halaman Qwiklabs Anda.

Import a Terraform Configuration

Tidak ada Check Progress

Pada tugas ini, Anda akan mempelajari cara mengimpor container Docker dan image NGINX yang sudah ada ke dalam state file Terraform tanpa harus membuat infrastruktur dari awal.

Langkah 1: Jalankan Container Docker

Buat container NGINX bernama hashicorp-learn menggunakan Docker CLI.

Bash

Langkah 2: Clone Repositori & Persiapan Impor

Unduh repositori latihan, sesuaikan versi provider Docker, dan atur struktur berkas konfigurasi Terraform.

Bash

Langkah 3: Impor Container ke dalam State Terraform

Definisikan resource kosong docker_container.web di docker.tf dan jalankan perintah terraform import.

Bash

Langkah 4: Buat Konfigurasi & Sinkronisasi Attribute

Salin hasil impor state ke docker.tf, ringkas atribut yang wajib saja, lalu jalankan terraform apply agar ter-sinkronisasi penuh.

Bash

Langkah 5: Tambahkan Resource Image & Ubah Port Container

Tambahkan deklarasi resource docker_image.nginx, tautkan ID image ke container, dan perbarui external port dari 8080 ke 8081.

Bash

Langkah 6: Hapus Seluruh Infrastruktur

Hapus semua resource yang dikelola oleh Terraform untuk mengakhiri tugas.

Bash
