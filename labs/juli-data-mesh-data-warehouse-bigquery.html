📦 Task 1: Create a table partitioned by date

Jalankan perintah berikut di Cloud Shell untuk membuat dataset target serta membuat tabel terpartisi:

🔍 Penjelasan Langkah & Konsep (Task 1)
  • bq mk --dataset: Membuat dataset kosong di project BigQuery Anda untuk menampung tabel-tabel lokal.
  • PARTITION BY date: Membagi penyimpanan data secara fisik berdasarkan hari/tanggal. Saat Anda melakukan query dengan filter rentang tanggal tertentu, BigQuery hanya memindai partisi tanggal tersebut sehingga menghemat penggunaan kuota scan data.
  • partition_expiration_days = 2175: Membatasi masa kedaluwarsa data partisi hingga 2175 hari. Setelah melampaui masa tersebut, data lama akan otomatis dihapus secara berkala demi efisiensi biaya.
  • alpha_3_code NOT IN ('GBR', 'BRA', 'CAN', 'USA'): Memfilter dan mengabaikan record dari empat negara tersebut dari tabel target Anda.
