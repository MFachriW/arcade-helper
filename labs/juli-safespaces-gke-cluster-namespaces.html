Task 2. View and create namespaces

Autentikasi ke cluster dan buat dua namespace baru (team-a dan team-b).

💡 Apa itu Kubernetes Namespace?
Namespace adalah cara Kubernetes membagi resource cluster tunggal menjadi beberapa "cluster virtual". Secara default, Kubernetes memiliki:
  • default: Digunakan jika tidak ada namespace yang disebutkan.
  • kube-system: Digunakan untuk komponen sistem inti Kubernetes.
  • kube-public: Resource yang bisa dibaca oleh semua pengguna.

Task 3. Access Control in namespaces

Gunakan kombinasi IAM Role dan Kubernetes RBAC (Role-Based Access Control) untuk membatasi akses developer hanya pada namespace tertentu.

💡 Perbedaan IAM dan RBAC
  • IAM (Identity and Access Management): Mengatur akses di tingkat Google Cloud Project. Di sini kita memberi akses minimal (Cluster Viewer) agar user bisa melihat cluster.
  • RBAC (Role-Based Access Control): Mengatur akses granular di dalam Kubernetes itu sendiri. Di sini kita menentukan bahwa user hanya boleh memodifikasi Pods di dalam namespace team-a.

Task 4. Resource quotas

Task 5. Monitoring GKE and GKE usage metering

Pantau penggunaan CPU/Memory melalui Console dan ekspor data tagihan (billing) ke BigQuery.

Langkah 5.1: Eksplorasi Monitoring Dashboard (Manual Console)

Langkah UI Console:
  1. Di menu Google Cloud Console, buka Monitoring (tunggu hingga workspace selesai dibuat).
  2. Di menu kiri, pilih Dashboards, lalu klik GKE.
  3. Lihat tabel Namespaces dan Workloads. Anda bisa mencoba memfilter berdasarkan namespace team-a.
  4. Di menu kiri, pilih Metrics Explorer. Cari metrik Kubernetes Container > Container > CPU usage time.

Langkah 5.2: GKE Usage Metering (BigQuery Export)

Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:

Cloud Shell Terminal
⚠️ Otorisasi BigQuery: Saat perintah bq query dijalankan, terminal mungkin akan meminta Anda untuk mengotorisasi. Klik link yang muncul, login dengan akun student Qwiklabs, salin kode otorisasi, lalu paste kembali ke Cloud Shell dan tekan Enter.

Langkah 5.3: Visualisasi di Looker Studio (Data Studio)

Buat visualisasi data dari BigQuery menggunakan Looker Studio.

Langkah UI Console:
  1. Buka Looker Studio (Data Studio) di tab baru.
  2. Klik Create > Data Source di kiri atas. Selesaikan setup akun (pilih negara, centang persetujuan, klik Continue).
  3. Pilih konektor BigQuery dan klik Authorize.
  4. Ubah nama di kiri atas menjadi GKE Usage.
  5. Pilih CUSTOM QUERY dari kolom pertama, pilih Project ID Anda.
  6. Salin Query SQL di bawah ini dan paste ke dalam kotak custom query, lalu klik CONNECT di pojok kanan atas.
