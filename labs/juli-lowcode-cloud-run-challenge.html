⚙️ Parameter Lab Kamu

📌 Langkah 1: Aktifkan API & Set IAM (Wajib Pertama)

Perintah ini berfungsi untuk mengaktifkan seluruh API Google Cloud Service yang dibutuhkan serta memberikan akses Pub/Sub Publisher pada Service Account Cloud Storage untuk mencegah error permission denied.

📦 Task 1: Create Storage Bucket

Perintah ini berfungsi untuk mengambil Project ID aktif di Cloud Shell dan membuat satu bucket Cloud Storage baru di region pilihanmu.

⚡ Task 2: Storage Function

A. Tulis Source Code

Perintah ini berfungsi untuk membuat folder project ~/hello-storage dan menyusun file source code index.js & package.json.

B. Deploy Cloud Function

Perintah ini berfungsi untuk men-deploy Event-Driven Cloud Function Gen 2 yang terhubung ke Cloud Storage bucket yang telah dibuat sebelumnya.

⚠️ PENTING (Mengatasi Error 403 / Permission Denied):
Jika kamu mendapatkan error seperti:
ERROR: (gcloud.functions.deploy) ResponseError: status=[403], ... Permission "storage.buckets.get" denied on "Bucket ... could not be validated ... Alasan: Error ini terjadi karena kebijakan akses IAM (IAM Policy Binding) yang kita daftarkan di Langkah 1 atau pembuatan Storage Bucket baru membutuhkan waktu sinkronisasi (eventual consistency/propagation delay) agar dapat dikenali sepenuhnya oleh sistem Eventarc Google Cloud.
Solusi: Jangan panik! Cukup tunggu sekitar 1 - 2 menit agar permission menyebar sempurna, lalu jalankan kembali perintah Deploy Cloud Function (Bagian B) di atas.

🌐 Task 3: HTTP Function

A. Tulis Source Code

Perintah ini berfungsi untuk membuat folder project baru ~/hello-http dan menyusun file source code aplikasi HTTP index.js & package.json.

B. Deploy Cloud Function

Perintah ini berfungsi untuk men-deploy Cloud Function Gen 2 bertipe HTTP trigger dengan konfigurasi penanganan instance secara otomatis.
