Langkah 1: Aktifkan API & Set IAM (Wajib Pertama)
Persiapan
Mengaktifkan seluruh API Google Cloud Service yang dibutuhkan serta memberikan akses Pub/Sub Publisher pada Service Account Cloud Storage untuk mencegah error permission denied. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - API & IAM Setup
Task 1: Create Storage Bucket
Task 1
Mengambil Project ID aktif di Cloud Shell dan membuat satu bucket Cloud Storage baru di region pilihanmu. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - Create Storage Bucket
Task 2: Storage Function
Task 2
A. Tulis Source Code
Membuat folder project ~/hello-storage dan menyusun file source code index.js & package.json. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - Write Storage Function Code
B. Deploy Cloud Function
Men-deploy Event-Driven Cloud Function Gen 2 yang terhubung ke Cloud Storage bucket yang telah dibuat sebelumnya. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - Deploy Storage Function
PENTING (Mengatasi Error 403 / Permission Denied)
Jika kamu mendapatkan error seperti:
ERROR: (gcloud.functions.deploy) ResponseError: status=[403], ... Permission "storage.buckets.get" denied on "Bucket ... could not be validated ... Alasan: Error ini terjadi karena kebijakan akses IAM (IAM Policy Binding) yang kita daftarkan di Langkah 1 atau pembuatan Storage Bucket baru membutuhkan waktu sinkronisasi (eventual consistency/propagation delay) agar dapat dikenali sepenuhnya oleh sistem Eventarc Google Cloud.
Solusi: Jangan panik! Cukup tunggu sekitar 1 - 2 menit agar permission menyebar sempurna, lalu jalankan kembali perintah Deploy Cloud Function (Bagian B) di atas.
Task 3: HTTP Function
Task 3
A. Tulis Source Code
Membuat folder project baru ~/hello-http dan menyusun file source code aplikasi HTTP index.js & package.json. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - Write HTTP Function Code
B. Deploy Cloud Function
Men-deploy Cloud Function Gen 2 bertipe HTTP trigger dengan konfigurasi penanganan instance secara otomatis. Untuk menyelesaikannya, jalankan perintah berikut di Cloud Shell:
Bash - Deploy HTTP Function
